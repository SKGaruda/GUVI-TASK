AWS VPC Setup 

> Create VPC
	1. Open VPC → Your VPCs → Create VPC
	2. Name: MyVPC
	3. CIDR: 10.0.0.0/16
	4. Create Internet Gateway
	5. Go to Internet Gateways → Create
	6. Name: MyInternetGateway
	7. Attach it to MyVPC

> Create Public Subnet
	1. Go to Subnets → Create subnet
	2. VPC: MyVPC
	3. Name: PublicSubnet
	4. CIDR: 10.0.1.0/24
	5. Select an Availability Zone
	6. Create Private Subnet
	7. Create another subnet
	8. VPC: MyVPC
	9. Name: PrivateSubnet
	10. CIDR: 10.0.2.0/24
	11. Select an Availability Zone

> Create Public Route Table
	1. Go to Route Tables → Create
	2. Name: PublicRouteTable
	3. VPC: MyVPC
	4. Add route:
	5. Destination: 0.0.0.0/0
	6. Target: Internet Gateway
	7. Associate PublicSubnet with this route table

> Launch Linux EC2
	1. Open EC2 → Launch Instance
	2. Select Amazon Linux
	3. Choose an instance type such as t3.micro
	4. Select/create a key pair
	5. VPC: MyVPC
	6. Subnet: PublicSubnet
	7. Enable Auto-assign Public IP
	8. Allow SSH (port 22) from your IP in the security group
	9. Click Launch Instance
