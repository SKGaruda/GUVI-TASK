Create a VPC
	• Go to VPC → Create VPC.
	• Select VPC and more.
	• Create 2 public subnets + 2 private subnets.
	• Click Create VPC.

Create security group for ALB
	• Go to EC2 → Security Groups → Create.
	• Name: ALB-SG.
	• Allow HTTP (80) from 0.0.0.0/0.

Create security group for EC2
	• Create another security group called EC2-SG.
	• Allow HTTP (80) from ALB-SG.

Launch EC2 #1
	• Go to EC2 → Launch Instance.
	• Choose Amazon Linux.
	• Choose your instance type.
	• Select a private subnet.
	• Select EC2-SG.
	• Install Apache using User Data.

Launch EC2 #2
	• Do the same thing.
	• Put it in the other private subnet/AZ.
	• Select EC2-SG.

Create Target Group
	• Go to EC2 → Target Groups → Create.
	• Target type: Instances.
	• Protocol: HTTP.
	• Port: 80.
	• Add EC2 #1 and EC2 #2.
	• Wait until both show Healthy.

Create Application Load Balancer
	• Go to EC2 → Load Balancers → Create Load Balancer.
	• Select Application Load Balancer.
	• Scheme: Internet-facing.
	• Select your VPC.
	• Select the 2 public subnets.
	• Select ALB-SG.

Configure the ALB listener
	• Listener: HTTP : 80.
	• Forward traffic to your target group.
	• Select the target group you created.
